# NiuLaiDeleter 自定義角色操作手冊

> 素材目錄:安裝版點角色視窗右上角"📖 自定義角色"按鈕開啟;開發版在專案 `assets/` 目錄。

## 一、目錄結構

```
assets/
├── niulai/                # 一個角色 = 一個資料夾
│   ├── 走路动效_spritesheet_transparent.png
│   ├── 指着文件_spritesheet_transparent.png
│   ├── 踹文件动效_spritesheet_transparent.png
│   ├── 爆炸_spritesheet_transparent.png
│   ├── 雷欧登场_spritesheet_transparent.png
│   ├── 出场飞行动效_spritesheet_transparent.png
│   ├── audio/             # 本角色的音訊(可選,預設用 assets/audio/ 兜底)
│   │   ├── bgm(1).mp3
│   │   ├── 怪兽说话.mp3
│   │   └── 爆炸.MP4
│   └── config.jsonc       # 完整配置模板:帶註釋,所有欄位說明都在裡面,複製改名即可用
└── audio/                 # 公共預設音訊(所有角色的兜底)
```

> 注意:資料夾命名建議用英文或拼音(如 `my_monster`),避免中文路徑。

## 二、最小要求:什麼才算一個角色

滿足下面任一條件的資料夾,重啟程式後就會被自動識別:

1. 資料夾裡有 `走路动效_spritesheet*.png` 或 `walk_spritesheet*.png`(完整角色,素材齊全)
2. 資料夾裡有 `config.jsonc` / `config.json`(染色變體,素材自動回退到第一個完整角色)

## 三、素材規格

- spritesheet 是 **5 列 × 3 行(共 15 幀)** 的網格拼圖:順序 = 第 1 行從左到右 → 第 2 行 → 第 3 行
- 推薦 PNG 透明底;同時存在 `xxx.png` 和 `xxx_transparent.png` 時,優先用 `_transparent` 版本
- 共需要 6 個動畫,預設檔名如下(可以在 config.jsonc 裡換名):

| 動畫 | 預設檔名 |
|---|---|
| 走路 | `走路动效_spritesheet.png` / `walk_spritesheet.png` |
| 指點 | `指着文件_spritesheet.png` / `point_spritesheet.png` |
| 踢踹 | `踹文件动效_spritesheet.png` / `kick_spritesheet.png` |
| 爆炸 | `爆炸_spritesheet.png` / `explosion_spritesheet.png` |
| 雷歐登場 | `雷欧登场_spritesheet.png` / `leo_spritesheet.png` |
| 飛離 | `出场飞行动效_spritesheet.png` / `fly_spritesheet.png` |

- 指點動畫預設只取第 12~15 幀(索引 11~14,即第 3 行第 2~5 格)
- 爆炸時機:踢踹動畫的第 6 幀(索引 5,可在 config 裡用 `kick_frame` 調整)

## 四、音訊(可選)

把音訊放進 `<你的角色>/audio/` 下,檔名與預設一致即可自動生效:

| 檔名 | 用途 |
|---|---|
| `bgm(1).mp3` | 背景樂(迴圈播放) |
| `怪兽说话.mp3` | 指點檔案時的音效 |
| `爆炸.MP4` | 爆炸音效 |

不放音訊 → 自動用 `assets/audio/` 裡的預設音訊。
想換檔名,就在 config.jsonc 的 `audio` 段寫明路徑(見第五節)。

## 五、config.jsonc 說明

配置檔名兩種副檔名都認:`.jsonc`(可帶註釋,編輯器不報紅線,推薦)優先,`.json`(嚴格 JSON,不帶註釋)兜底。新建角色時,把 `assets/niulai/config.jsonc` 複製到自己的資料夾裡再改即可——只改關心的欄位,其餘保持原樣也不會出錯。

config.jsonc 支援註釋:`//` 開頭是行註釋,`/* */` 是塊註釋(字串裡的會原樣保留)。模板裡每個欄位都帶中文說明,直接看檔案就能明白。

所有欄位都可省略,省略項自動用預設值。完整示例:

```jsonc
{
  "id": "my_monster",                 // 唯一標識;改資料夾名不影響已儲存的預設角色
  "name": "我的怪獸",                  // 顯示名;預設用資料夾名
  "description": "隨便寫點介紹",

  "sprites": {
    "walk": "我的走路.png",            // 各動畫的檔名
    "point": "我的指點.png",
    "kick": "我的踢踹.png",
    "explosion": "我的爆炸.png",
    "leo": "我的登場.png",
    "fly": "我的飛離.png",
    "point_frames": [11, 12, 13, 14]   // 指點動畫取哪幾幀(從 0 數起)
  },

  "audio": {
    "bgm": "audio/我的背景樂.mp3",
    "voice": "audio/我的說話.mp3",
    "explosion": "audio/我的爆炸.mp3"
  },

  "texts": {
    "targeting": "請選擇你要摧毀的檔案",   // 狙擊時的提示文字
    "dialog": "喂，是這個嗎？",            // 對話氣泡文字
    "choice_yes": "是的",                  // 確認按鈕
    "choice_no": "嚶嚶嚶就是這個",         // 再挑一個按鈕
    "swap": "換一隻"
  },

  "animation": {
    "fps": 8,                  // 動畫幀率
    "sprite_height": 250,      // 角色顯示高度(像素)
    "walk_duration_ms": 4500,  // 走路入場時長(毫秒)
    "explosion_height": 150,   // 爆炸圖顯示高度(像素)
    "walk_y_offset": 50,       // 走路時角色相對目標點的垂直偏移(像素,正=偏下)
    "target_gap": 30,          // 角色手指與目標檔案的水平間距(像素,越小越貼近)
    "kick_frame": 5,           // 踢踹動畫第幾幀觸發爆炸(0 起,預設 5=第 6 幀)
    "fly_duration_ms": 2000,   // 飛離動畫時長(毫秒)
    "explosion_y_offset": 40   // 爆炸圖相對目標點上移量(像素)
  },

  "tint": { "color": "#ff0000", "strength": 0.6 }
}
```

## 六、染色變體:不動圖換皮

資料夾裡只放一個 config.jsonc,不複製任何圖片,素材自動回退到 `niulai`(第一個完整角色)。只需上色:

```jsonc
{
  "id": "gold_monster",
  "name": "黃金角色",
  "description": "土豪金",
  "tint": { "color": "#ffd700", "strength": 0.7 }
}
```

`tint.strength`:0 = 不變色,1 = 完全染成目標色。
注:染色配合 `_transparent.png`(透明底)素材效果最好。

## 七、改完怎麼生效

直接重啟程式即可,角色自動重新掃描,無需重新打包。
在角色選擇視窗能看到新角色的卡片 = 成功;
右鍵召喚用的是上次選中的預設角色,記得先在角色視窗選一次。

## 八、角色分發(打包給別的使用者)

一個角色 = 一個資料夾,內容自包含(貼圖 + audio/ + config.jsonc)。
分發方法:

1. 把 `<角色資料夾>` 壓縮成 zip(右鍵資料夾 → 壓縮)
2. 把 zip 發給對方
3. 對方解壓後,把整個資料夾放進自己的 assets 目錄(點角色視窗右上角"📖 自定義角色"開啟的目錄),重啟即用

> 提示:右鍵卡片還能"編輯配置檔案"(帶高亮的編輯器,可改可存),方便檢查和分享配置。
