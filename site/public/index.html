這 到 底 是 什 麼

一個 Windows 右鍵選單擴充。你選一個檔案，牠負責把它刪掉。 中間會多花大約 9 秒，做一些完全不必要的事。

功能 1

牠會自己找到檔案

程式會去讀檔案總管的清單，算出你那個檔案圖示在螢幕上的實際座標。 不是抓滑鼠位置——因為你右鍵的時候游標早就跑到選單上了。這部分意外地認真。

功能 2

牠真的會踹

踢腿動畫的第 5 幀觸發爆炸，同一刻檔案進資源回收筒。 時間點是對齊的，不是先刪再演給你看。

功能 3

你可以換一隻

一個資料夾 = 一隻角色。丟六張 5×3 的 spritesheet 進去就多一隻。 懶的話只寫一個設定檔調色，就能生出一隻同款不同色的。

前往下載頁

裝的時候會被 Windows 攔一次。 安裝檔沒有買數位簽章，所以會跳出藍色的「Windows 已保護您的電腦」， 而且預設只給你一顆「不要執行」。請點左下角那個很不明顯的 「其他資訊」，再點 「仍要執行」。

裝完要先自己打開一次。 右鍵選單是程式啟動時才寫進登錄檔的，沒開過就不會有右鍵選單。 開啟後在角色視窗選一次角色，右鍵選單的文字才會定下來。

常 見 問 題

檔案是真的被刪掉嗎？還是只是演戲？

真的刪。用的是系統的資源回收筒 API，跟你按 Delete 是同一個去處，所以救得回來。 爆炸那一幀跟刪除是同時觸發的。

需要系統管理員權限嗎？

不用。是每使用者安裝，右鍵選單只寫進 HKCU。解除安裝時會自己清乾淨。

牛指錯地方怎麼辦？

會發生。多螢幕不同縮放比例、系統地區設定改過、或裝了桌面整理軟體接管圖示， 都可能讓定位失準。定位失敗時程式不會亂猜，會自動切成十字準星讓你手動點。

可以換成別的動物嗎？

可以。一個資料夾 = 一隻角色，準備六張 5 列 × 3 行、共 15 格的 spritesheet （走路／指點／踢踹／爆炸／登場／飛離）丟進素材目錄就行。 詳細規格看 repo 裡的自定義角色操作手冊。
